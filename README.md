# lms-android-kumalatova

Приложение для Android: показывает администратору обращения с сайтов, где стоит плагин `lms-plugin-app-kumalatova`. Тёмная тема.

Блоки 3, 4 и 5: каркас, фоновые уведомления со звуком, ответ из приложения. Настройки Xiaomi и Huawei — Блок 6.

## Как получить приложение

Каждый push в `main` собирает APK на GitHub. Готовый файл лежит в разделе Releases, релиз `latest`, файл `lms-admin.apk`. Скачайте на телефон и установите вручную. Новый файл ставится поверх старого, данные сохраняются.

## Структура

```
settings.gradle.kts, build.gradle.kts, gradle.properties   настройки проекта
.github/workflows/build.yml                                 сборка APK и релиз latest
app/build.gradle.kts                                        зависимости, подпись
app/debug.keystore                                          ключ подписи (один на все сборки)
app/src/main/AndroidManifest.xml
app/src/main/res/                                           тема, значок, строки
app/src/main/java/com/kumalatova/lmsadmin/
    MainActivity.kt    запуск, запрос разрешения на уведомления, QR-сканер, вход из уведомления
    PollService.kt     служба на переднем плане: опрос сайтов раз в 30 секунд, уведомления
    Notifier.kt        каналы (свой на каждый сайт), уведомления, запоминание показанного
    BootReceiver.kt    запуск слежения после перезагрузки и обновления
    AppViewModel.kt    сайты, значки, списки, переписка
    Screens.kt         главная, сайт, переписка
    Theme.kt           цвета
    Api.kt             запросы к плагину (заголовок X-LMS-Key, только https)
    SiteStore.kt       список сайтов в закрытом хранилище приложения
    Models.kt, Format.kt
```

## Как работает

- Сайт добавляется по адресу и ключу вручную или сканированием QR-кода со страницы «Курсы → Мобильное приложение» (плагин 0.2.1 и новее). Если сайт не подключился, на экране добавления написана причина (ответ сайта, код ошибки).
- Главная: строка = сайт, справа оранжевый значок с числом непрочитанных. Нажатие открывает сайт: вкладки «Тикеты», «Преподавателям», «Магазин» и список обращений. Долгое нажатие на строку сайта предлагает его удалить.
- Пока приложение открыто, сайты опрашиваются раз в 30 секунд.
- Фон: служба на переднем плане с постоянным значком в шторке опрашивает сайты раз в 30 секунд. О каждом новом обращении приходит уведомление «сайт, кто, тема», видно на экране блокировки. Нажатие открывает переписку. Прочитанное и отвеченное из шторки убирается само.
- У каждого сайта свой канал уведомлений. Кнопка «Звук» на экране сайта открывает его системные настройки, там выбирается мелодия. Первый опрос нового сайта проходит без звука: накопившееся запоминается.
- Ответ: поле внизу переписки. Тикет отвечает от администратора, диалог от имени преподавателя, кому адресовано сообщение.
